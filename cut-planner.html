3. Optimize

Parts may rotate 90°

Uses multiple guillotine-cut packing heuristics for sheets and lumber, including side-by-side parts across board width. Minimum material favors fewer sheets. Balanced sheet layouts trade a limited increase in material for fewer cuts and fewer sideways parts. Lumber always prioritizes board count. This is heuristic optimization, not a guaranteed global optimum. No grain direction constraints.

1. Workflow overview

  1. Choose units. Use Units in the top banner to switch between inches and millimeters.
  2. Define stock materials. Enter each sheet or board size, thickness, and a recognizable material name.
  3. Add your parts. Import a SketchUp file or CSV, or enter names, dimensions, quantities, and material assignments manually. Review every imported list.
  4. Set cutting preferences. Enter blade kerf and any edge trim. Choose a sheet layout goal and optimization quality.
  5. Optimize cut plan. Review totals, diagrams, repeated-layout instructions, and cut positions. Change settings and re-optimize to compare alternatives.
  6. Save and print. Download your project JSON, then use Print / Save PDF to take the plan to the workshop.

Try it first: Load example supplies sample stock and parts. Use it before entering your own project; loading an example replaces the current working data, so save your project first.

Before cutting: verify actual stock sizes, part quantities, dimensions, blade kerf, grain needs, and the cut sequence. The optimizer produces a heuristic plan, not a guarantee of the safest or least-waste cutting method.

2. Stock materials and parts

Stock materials

Create separate materials for different wood types, thicknesses, or stock sizes. A sheet uses width and length; lumber uses board width and board length. The planner may allocate multiple identical stock pieces as needed. Materials are optimized separately.

Part dimensions

Give each part a useful name, width, length, thickness, quantity, and a stock material. Thickness must match the assigned material (within 0.001 inch). The part must fit within usable stock after edge trim.

Dimension fields accept decimals or inch fractions such as 3/4 and 14 1/2. Input tables display decimals. In the results, inch measurements that lie exactly on a 1/32-inch increment display as reduced fractions; finer values remain decimals. Millimeter values stay decimal.

Enter the actual cut size you need. Add allowances for tenons, tongues, fitting, or later trimming yourself; the planner does not add joinery allowances automatically. Rotation by 90° is allowed, and there is no configurable grain-direction constraint.

Add / remove: use Add material or Add part to create rows. The red × removes a row. Removing a material can leave parts without a valid assignment; reassign those parts before optimizing.

3. Importing parts

SketchUp (SKP)

Select Import SketchUp (SKP), then choose your model. The importer groups matching physical parts, extracts dimensions and quantities, and can create stock entries based on thickness. Those stock entries are starting points: review their sizes, material names, and whether they should be sheets or lumber.

Hidden content is excluded by default. Enable Include hidden parts before importing if you deliberately need it. The import report lists skipped or ambiguous items. Expand its review section and use Add as part for a recoverable skipped item only after checking that it is a real part and not an assembly wrapper.

Direct SKP import is beta. Model structure and geometry can affect extraction; compare representative parts and counts with SketchUp before relying on a plan. Importing an SKP replaces the working parts list. Save your project first.

CSV

Use CSV template for the expected columns: name,width,length,thickness,quantity,material. A CSV material name must match an existing stock material. Dimensions are interpreted in the currently selected units; choose the correct Units setting before importing. Export parts CSV downloads a parts list, not a complete saved project.

Assembly Viewer

After importing an SKP, expand Assembly Viewer below the cutting layouts. Drag to orbit, right-drag to pan, and scroll to zoom; on touch screens use one finger to orbit and two to pan and zoom. Fit model frames the full import, Reset camera restores the full isometric view, and Projection switches perspective or orthographic views.

Use disclosure arrows to expand the assembly hierarchy. Select an assembly to focus it, select a part to highlight it and inspect modeled dimensions in inches, and use checkboxes to hide components. Neutral surfaces show parsed faces; blue wireframes indicate approximate bounding boxes. Check any geometry review notes. Imported materials and textures are not reproduced.

This first viewer displays assembled positions. Exploded views and assembly diagram exports are planned. Cut-list edits and manufacturing allowances do not change the imported model. Saved project JSON contains the cut list only: reimport the original SKP to restore the viewer. Loading the example, opening a saved project, or clearing the project clears the viewer.

4. Choosing a planning strategy

Balanced — fewer cuts (default)

Start here for a practical sheet-cutting plan. Balanced considers waste, numbered cut operations, and parts turned sideways across the long direction of the sheet. It can accept some additional stock when the simpler cutting plan justifies it.

The extra-sheet allowance is limited per material group: one extra sheet for small projects, or 15% of the minimum-material baseline rounded down when that is larger. It does not automatically spend that allowance. It is a preference for simpler plans, not a grain lock or a guarantee that every part has the same orientation.

Minimum material

Choose this when sheet cost or limited stock is the priority. It searches for fewer sheets and fuller early sheets, allowing rotations and more involved cutting where that helps packing. Compare it with Balanced using Number of Cuts and Total Waste % in the summary.

Lumber packing

Lumber parts can share a board's width side by side, with kerf between them. For example, a 6-inch board can hold two 2.5-inch strips if the configured kerf and margins leave enough room. The planner prefers the longer fitting part dimension along the board. Lumber prioritizes board count; the sheet layout goal does not change lumber packing. Its sequence includes both rip cuts and crosscuts.

Kerf, trim, and optimization passes

  • Blade kerf: material removed by the blade. Measure or verify it for your saw; the starting value is 0.125 inch.
  • Edge trim / margin: allowance on every stock edge. A margin reduces usable width and length by twice that value.
  • Optimization passes: Fast, Better, and Thorough try increasing numbers of arrangements. More passes take longer and may improve a plan; they do not guarantee the global optimum. Balanced evaluates additional alternatives.
  • Diagram text size: changes the diagram's display scale; it does not change part dimensions or packing.

A useful comparison: save your project, optimize with Balanced, note sheets/boards, cuts, and waste, then switch to Minimum material and optimize again. Choose the plan that best suits your stock and workshop workflow. Always re-optimize after changing parts, stock, or cutting settings.

5. Reading the output

Summary

The summary counts all physical parts, sheets, boards, and cut operations, even when identical layouts share a page. Total Waste % is weighted by stock area across all sheets and boards; it includes kerf, edge trim, and offcuts. The percentage does not distinguish useful reusable offcuts from scrap, and is not a cost- or thickness-weighted calculation.

Diagrams and labels

Letter bubbles identify part types and link diagrams with the parts tables. Numbered dark bubbles identify cutting steps. Dashed lines indicate planned cut locations. Dimensions follow the edges they measure; text may shrink or move on small parts. Narrow lumber diagrams may modestly exaggerate width for readability, so use the written measurements rather than measuring the drawing.

Repeated layouts

A heading such as Sheets 1–3 · Repeat 3 times means to use that plan on three sheets. Matching layouts share one screen card and printed layout page. A heading such as Boards 1, 3 names only those boards; board 2 has a different plan. Parts quantities and cut sequences on a shared plan apply to each listed stock piece.

Cut span versus position

  • Cut span: the full distance the cut travels through the current piece. It may include stock removed by later cuts, so it can exceed a finished part dimension.
  • POSITION: the distance from the current piece's reference edge. Sheet cuts reference left/top edges; lumber references the board start for crosscuts or its side edge for rips.
  • From cut N edge: an earlier cut created the reference edge. Distances account for kerf; measure from the remaining piece's actual edge, not the original stock edge.
  • Completion checkbox: tracks progress on the displayed plan. For a repeated plan, repeat the sequence on every stock piece. Checkboxes are working aids and are not saved as project progress.

6. Save, reopen, and print

  • Save icon: downloads a complete project JSON with stock, parts, units, kerf, margin, sheet goal, and diagram scale. Save before closing or refreshing the app.
  • Open folder icon: loads a saved project JSON. Review it and optimize again to generate the cutting layouts.
  • Trash icon: clears the current project after confirmation. It does not delete JSON files you have already downloaded.
  • Print / Save PDF: opens your browser's print dialog. Choose a printer or its PDF destination. Output includes a project cover/parts list and a page for each distinct layout.

There is no automatic project backup, account, or cloud synchronization. A saved JSON is the reusable project; a PDF is a shop reference. Keep both when useful. Hover over the banner icons to see their actions.

7. Using the mobile layout

Materials and parts appear as compact rows. Tap a row's Edit control to expand its fields; tap Done to collapse it. Only one row editor stays open at a time. The red × is available without opening the row. Newly added rows open for editing automatically.

After optimization, the generated Parts List, Parts on this sheet/board, and Cut sequence sections start collapsed. Tap Show or Hide to control them. Printed output still includes their contents. Controls wrap to fit the screen, and sheet diagrams appear above their associated tables.

The circular-arrow refresh icon sits with the other banner controls in the PWA. The question-mark Help icon opens this guide. Tap Close or press Escape on a keyboard to return to your unchanged plan.

8. Offline use, installation, and updates

Local files: open the source cut-planner.html with its vendor folder alongside it, or open the distributed index.html on its own. The distributed file embeds the parser and this guide. No local app server is required.

Installable app: visit the published HTTPS site online, wait for Ready for offline use, then use Install app or the browser's install menu. On iPhone/iPad, use Share → Add to Home Screen (Safari if the option is missing). Installation needs an online visit; once cached, the planner and SKP import can work offline. Clearing browser storage can require another online visit.

Updates: while online, the PWA checks the published version on launch, focus, reconnection, and each minute while visible. A green top banner and dot on Refresh indicate a newer version. Save your project JSON, then select Refresh and confirm. No update automatically reloads an open plan. Offline or suspended apps check again when they reconnect or return to use.

Installing the app does not save the current project. Download JSON before closing, installing, or refreshing. The standalone local file has no live update check; replace it with a newer distributed file when needed.

9. Common questions

  • A part cannot fit: check stock width/length, part dimensions, thickness assignment, and trim. Confirm the material is a sheet or lumber as intended.
  • Too many sheets or cuts: compare Balanced with Minimum material, try more passes, check quantities and margins, and look for accidental duplicate or oversized parts.
  • Lumber still will not fit across: include kerf between strips and trim on both outside edges. Two 2.5-inch strips need more than 5 inches of usable width when kerf is nonzero.
  • A number looks too large: distinguish Cut span from finished size and POSITION. A later cut may remove the extra material.
  • SketchUp parser is missing: restore the vendor folder beside the source HTML, or use a fresh self-contained index.html distribution. No browser security setting needs to be disabled.
  • A project disappeared after closing: use Open project to restore the JSON you downloaded. Unsaved browser state cannot be recovered by reopening the app.
