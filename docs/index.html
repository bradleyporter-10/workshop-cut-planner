3. Optimize

Parts may rotate 90°

Uses multiple guillotine-cut packing heuristics for plywood and best-fit board allocation for lumber. Aims to minimize the number of raw sheets/boards first, then unused area/length. This is heuristic optimization, not a guaranteed global optimum. No grain direction constraints.
